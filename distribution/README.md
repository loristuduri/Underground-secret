# Distribution multicanal

## Outils envisagés
- Metricool : calendrier éditorial et publication selon les comptes autorisés
- vidIQ : recherche de sujets, optimisation YouTube et analyse
- GitHub : versionnage des scripts et métadonnées
- Google Drive : stockage des médias lourds
- GitBook : documentation du projet, synchronisation à configurer

## Circuit de validation
Brouillon → Relecture factuelle → Validation créative → Export → Programmation → Publication → Analyse.

Ne jamais publier automatiquement sans autorisation explicite. Les possibilités réelles dépendent des connexions et des API.
