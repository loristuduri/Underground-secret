# UNDERGROUND SECRET

Studio éditorial et audiovisuel consacré aux mystères archéologiques, aux sites monumentaux et aux enquêtes documentaires.

## Ligne éditoriale
- Distinguer faits établis, hypothèses scientifiques et spéculations.
- Citer les sources et signaler les incertitudes.
- Visuels réels et reconstitutions IA clairement identifiés.
- Vidéos verticales 9:16, narration française, sous-titres et atmosphère d'enquête.

## Organisation
- `episodes/` : dossiers éditoriaux par case.
- `studio/` : pipeline de production vidéo.
- `docs/` : documentation prévue pour GitBook.
- `distribution/` : diffusion et suivi multicanal.
